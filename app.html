🏭 Normal Distribution

Manufacturing Quality Control

1. Industry Problem

A factory manufactures metal rods with a target length. Due to small manufacturing variations, the actual length of each rod may differ slightly. The normal distribution helps engineers understand these variations and identify products that do not meet quality standards.

2. Learning Objectives

  • Understand the bell-shaped probability curve.
  • Learn the role of mean and standard deviation.
  • Understand manufacturing tolerances.

3. Input Parameters

4. Mathematical Formula

f(x) = 1 / (σ√2π) × e−(x−μ)² / 2σ²

μ = Mean, σ = Standard deviation, x = Observed rod length.

☁️ Exponential Distribution

Cloud Request Inter-arrival Time

1. Industry Problem

A cloud server receives requests from multiple users. The exponential distribution models the waiting time between consecutive requests and helps engineers understand server traffic patterns.

2. Learning Objectives

  • Understand the exponential probability distribution.
  • Learn the meaning of the arrival rate.
  • Understand waiting time between requests.

3. Input Parameters

4. Mathematical Formula

f(x) = λe−λx, x ≥ 0

λ = Average request arrival rate, x = Time between requests.

📦 Central Limit Theorem

Warehouse Processing Time

1. Industry Problem

A warehouse processes customer orders. Each order takes a different amount of time. The Central Limit Theorem explains how the average processing time of repeated samples tends to follow a normal distribution.

2. Learning Objectives

  • Understand sample means.
  • Learn the importance of sample size.
  • Understand the sampling distribution.

3. Input Parameters

4. Mathematical Formula

Z = (X̄ − μ) / (σ / √n)

X̄ = Sample mean, μ = Population mean, σ = Population standard deviation, n = Sample size.
